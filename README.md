# Reaction Speed Test

A browser-based reaction game developed using HTML, CSS, and JavaScript.

---

## Overview

This project is an interactive web application where users test how quickly they can respond to a visual target. The objective is to click the target as fast as possible once it appears on the screen.

The application focuses on timing accuracy, user feedback, and overall usability.

---

## Features

- Multiple difficulty levels (Easy, Normal, Hard)
- Countdown phase before each round
- Random delay to prevent prediction
- Early click penalty system
- Reaction time tracking
- Round-by-round performance history
- Persistent high scores using localStorage
- Optional sound feedback
- Keyboard controls for accessibility
- Responsive design for different screen sizes

---

## How to Use

1. Open the website  
2. Select a difficulty level  
3. Start the game  
4. Wait for the target to appear  
5. Click as quickly as possible  
6. View results on the score page
